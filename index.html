为什么需要 Blackout Mode？

传统的熄屏和电源休眠会导致 macOS 清除显示器图形拓扑结构，造成后台截图、AI Computer Use 代理或远程桌面无法正常工作。Blackout Mode 完美解决了这一难题。

传统熄屏 / 休眠
❌ 无信号 / 拓扑断开
  • ✕ 系统发送屏保/显示器关机命令，断开 DDC 连接
  • ✕ 后台截图捕获到黑色全空帧或引发系统渲染异常
  • ✕ Computer Use AI 代理由于无法读取 UI 元素而中断

  • ✓ 无需物理遮挡屏幕，节能护眼，完美契合 AI 挂机与自动化测试

体验屏幕唤醒防护与快速恢复机制

KeepAwake 挂载了独立 Watchdog 守护进程。支持通过鼠标晃动或连续按键 3 次迅速解锁回复原亮度。

灵活预设定时器

提供 15 分钟、1 小时、3 小时、直到早上 8:00 以及永久保持唤醒等多种快捷时长，菜单栏直观倒计时展示。

多显示器 DDC/CI 控制

内置屏采用 DisplayServices，外接显示器优先使用 DDC/CI VCP 指令调亮降至 0，不支持时自动 Gamma 降级。

Watchdog 守护与恢复

Blackout 写入临时恢复文件并启动独立 Watchdog；即使主进程异常崩溃退出，守护进程也会安全将亮度复原。

锁屏与密码保护

KeepAwake 仅响应防空闲休眠断言，不修改系统的屏保、密码解锁或合盖认证策略。不会绕过 macOS 的身份验证机制。

常见问题解答

1. 为什么项目名称是 CoffeeORTea 但生成 App 是 KeepAwake？ +

CoffeeORTea 是仓库全名与代号，灵感来自于用咖啡（☕️）或茶（🍵）提神保持清醒。KeepAwake 是用户系统菜单栏中实际显示的应用名称。

2. 所有外接显示器都能完美支持 DDC/CI 亮度调零吗？ +

DDC/CI 的支持取决于显示器固件、HDMI/DP/Type-C 转接线以及 Apple Silicon 接口层。KeepAwake 提供了双重降级方案：若 DDC 无响应，会自动使用 macOS Gamma 曲线衰减机制将亮度屏幕调暗。

3. Blackout Mode 如何恢复显示？ +

快速摇晃/移动鼠标，或者在 2 秒内连续按键盘任意键 3 次，或者通过系统菜单栏图标关闭开关键，都能触发亮度瞬间还原。

关于 KeepAwake

KeepAwake 是一款 100% 原生 macOS 菜单栏应用，可在开启期间阻止系统和显示器空闲休眠，但不会绕过手动锁屏或身份验证。

包含息屏模式，可安全地将显示器亮度降至 0%，适用于自动化代理和省电场景。

功能特色：
  • • DDC/CI 外接显示器亮度控制
  • • 不支持的显示器使用 Gamma 降级方案
  • • 通过鼠标/键盘安全自动恢复
使用 Swift 和 AppKit 构建。
